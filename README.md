# KASUMI — Cinematic Japanese Minimal

A premium cinematic landing page inspired by restrained Japanese editorial art direction and immersive Awwwards-style motion.

## Stack

- Next.js 15
- React 19
- TypeScript
- GSAP + ScrollTrigger
- Lenis smooth scrolling
- Three.js + custom GLSL atmospheric hero
- Responsive desktop / tablet / mobile motion system

## Included experience

- Cinematic numeric preloader
- Procedural WebGL mist hero
- Minimal floating navigation
- Fullscreen animated menu
- Live Tokyo and Copenhagen clocks
- Masked serif typography reveals
- Large editorial whitespace
- Subtle image parallax
- Sticky Material / Light / Rhythm sequence
- Organic radial image transitions
- Alternating project storytelling
- Custom desktop cursor
- Light editorial journal interlude
- Full-bleed closing image
- Spacious film-credit-style footer
- prefers-reduced-motion support
- Mobile-specific simplified animation behavior

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production

```bash
npm run build
npm start
```

The repository is ready to import into Vercel using the default Next.js settings.

## Creative direction

This is an original concept brand named **KASUMI**. It recreates the restrained pacing, negative-space composition, typography hierarchy, and cinematic interaction language of high-end Japanese editorial websites without copying proprietary source code, branding, or assets.
